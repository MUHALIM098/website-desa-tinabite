Folder ini untuk menyimpan Model — class atau fungsi yang berisi query ke database Supabase.

Contoh model yang akan dibuat di tahap berikutnya:
- beritaModel.js   → query tabel berita
- umkmModel.js     → query tabel umkm
- perangkatModel.js → query tabel perangkat_desa
- galeriModel.js   → query tabel galeri

Setiap model hanya berisi fungsi query, tidak ada logika bisnis.
Logika bisnis ada di controller atau service.
